# Node.js et npm

## Qu’est-ce que Node.js ?

Node.js est un environnement d’exécution qui permet d’exécuter du JavaScript en dehors d’un navigateur. Il est notamment utilisé pour développer des applications côté serveur.

Notre application NestJS s’exécutera donc avec Node.js.

## Qu’est-ce que npm ?

npm est un gestionnaire de paquets qui permet d’installer les bibliothèques nécessaires au projet, de gérer leurs versions et d’exécuter les scripts définis dans `package.json`.

## À quoi servent-ils dans notre projet ?

NestJS repose sur Node.js. npm nous permettra d’installer les dépendances nécessaires à notre système d’authentification, comme Passport, les bibliothèques JWT et TypeORM.

## Pourquoi ce choix ?

On utilise Node.js parce que c’est l’environnement d’exécution de notre application NestJS. On utilise npm pour gérer les dépendances du projet.

## À retenir

- Node.js exécute notre application.
- npm permet d’installer et de gérer ses dépendances.

Documentation : [Node.js](https://nodejs.org/) · [npm](https://docs.npmjs.com/)
